# 我修我再修 / FOGBOUND

俯视像素风、支持单人及最多 5 人联机的 1 对 4 生存游戏。

游戏数值集中在 [src/game-config.json](src/game-config.json)，修改方法见 [CONFIGURATION.md](CONFIGURATION.md)。房屋增加室内隔墙窗和板区；楼梯区分上下，地下室入口带血迹。手机右下角为攻击键，搬运按钮按条件出现，提示消息位于顶部。求生者倒地也能立即进入开启的地窖。治疗进度属于受治疗者，多人治疗共同加速；人物栏显示失血条及唯一追逐目标。

完整参数字典见 [CONFIG-FIELDS.md](CONFIG-FIELDS.md)。木板使用恢复后的原版外观，立起、倒地与破碎状态由主机同步。每局地上 11 钩、地下室 4 钩；玩家自然搬运挣脱 32 秒，AI 22 秒，主动挣扎会进一步加快。

## 联机

在 GameHub 登录后打开游戏，点击「创建 / 加入联机房间」。创建者可分享 6 位房间号，给空位添加或移除 AI；5 个席位就绪后开始。房间固定 4 名求生者和 1 名杀手。

使用 GameHub 已部署的 `/api/v1/rooms` 与 `/ws/rooms` 房间服务，房主统一运行对局并发送压缩快照，其他客户端发送操作。无需独立端口或额外后端服务，也不会把发布凭据放入游戏包。房间消息低于平台每秒 20 条、单包 8 KB 的限制。

房主关闭页面、离开房间或失联超时，房主所在阵营失败。非房主掉线由 AI 接管；自己的网络断开不会错误判对方失败。对局中不接收新玩家，联机菜单不会暂停其他人的对局。

## 运行

```sh
npm install
npm run dev
```

打开 http://localhost:5186 。`npm run build` 构建至 `dist`，`npm test` 检查规则。

## 操作与规则

- WASD 移动，鼠标控制双方朝向和视野；Shift 奔跑，鼠标右键 蹲行。
- 按住鼠标左键修机；按住 E 治疗、救援、开门、破板或挂钩；Space 放板、翻越、校准、上下楼及跳落。
- 屠夫左键轻点攻击，长按蓄力后释放突进；R 抱起或放下。
- 木屋两处楼梯连接一、二楼，二楼南侧箭头处可单向跳落。楼层独立碰撞、视线和交互，AI 能上下楼寻路。每局二楼固定有一台发电机。
- 北侧增加三角绕点，东侧增加双板区。板子破坏后不能再次使用。
- 双方使用约 140° 前方视野及近身感知圈，高墙遮挡墙后角色与亮区，矮地形不遮挡视线但保留碰撞。视野外地形暗显，角色隐藏；高低围墙以规整墙体和破败碎石材质区分。
- 双方出生距离至少 750；持续修机锁定当前发电机，不会被靠近的受伤队友打断。
- 按住 E 进出衣柜或搜柜，柜内可观察外部；藏柜 20 秒后暴露位置，每 15 秒重复提醒。搜出求生者后直接抓取搬运。
- 追逐时播放 168 BPM 电子合成 BGM，治疗时循环播放治疗音效。三挂、流血死亡和四趴触发灵魂升天动画；四趴四人同时死亡，动画结束后结算。
- 奔跑迎向板口放板会顺势通过，受阻时不强制穿越。屠夫命中后擦刀恢复 3.2–4 秒。
- AI 会协调救援、避开重复治疗、优先推进有进度的电机，屠夫会预判移动和巡查重点电机，寻路会避开挡路角色。
- 七台发电机修好五台后开门。两次命中倒地，第三次挂钩献祭；钩上每阶段 60 秒。
- 四人全部倒地立即判负；最后一名存活者在钩上时立即献祭。仅剩一名存活者时地窖开启。
- 挂钩队友有方向、距离和楼层提示；屠夫获得持续 8 秒的救援发生位置提示，不追踪被救者的实时位置。
- 被队友治疗时显示治疗者、百分比和进度条。
- 心跳随屠夫接近变响、加速，另有屏幕提示。Esc 暂停，切换窗口自动暂停。

## 音效素材

音效本地加载，不依赖运行时外网。木材、金属、衣料、挥刀和脚步使用 Kenney 的 Impact Sounds / RPG Audio（CC0）。命中与挂钩穿刺使用 Will Leamon 的 Fleshy Fight Sounds（OGA-BY 3.0）。

Additional Sound FX by Will Leamon

心跳使用低通处理的柔性撞击采样构成双拍。素材许可证、署名和运行时处理说明位于 `public/audio/`，设置页也提供署名链接。未使用原作提取素材。

## 验证

- `npm test`：规则、楼层、鼠标视野、结算和反馈回归。
- `node --import tsx scripts/simulation-check.ts`：16 个随机种子的完整 AI 对局。
- 启动开发服务后，`node scripts/feedback-browser.mjs`：鼠标视野、方向标记、治疗进度、上下楼、跳落、蓄力、挂钩、救援、破板和音频加载检查；截图输出至 `artifacts/`。

## 结构

`src/game.ts` 对局规则与 AI；`src/world.ts` 地图、碰撞和寻路；`src/scene.ts` 渲染与输入；`src/main.ts` / `src/style.css` 菜单和 HUD；`src/audio.ts` 采样播放与动态心跳。

本轮反馈更新：突刺具有后拉、连续前冲、刺出和收刀阶段，接触阶段判定命中；武器显示为刀具。求生者胸口心脏随杀手接近增大、加快，并与增强的双拍音效同步。修机、治疗、救援、挂钩、踢机和破板使用独立交互姿势，修机有持续机械声与工具声。

机械声采用 jwiese 的 Engine/Mechanic working sound（CC0）：https://opengameart.org/content/enginemechanic-working-sound 。

额外浏览器检查：`node scripts/lunge-browser.mjs`、`node scripts/interaction-browser.mjs`、`node scripts/audio-check.mjs`。

## 手机横屏与蹲行

- 手机横屏游玩；浏览器支持时请求方向锁定，否则竖屏展示旋转提示并冻结对局。电脑（包括触屏电脑）保留键鼠布局。
- 摇杆偏移8像素内静止，内圈慢走72，达到半径70%后奔跑112；蹲行按钮切换蹲下，速度30，推满也不会奔跑。电脑按住鼠标右键蹲行，优先于Shift。
- 人物作为扇形光源，自己的角色完整显示，不受迷雾裁切。树木正常显示且不遮挡视线；房屋实墙、普通围栏自身可见，只遮住后方区域。双方站立和蹲行遵循同一遮挡规则。

- 手机修机点按开始，再点停止，移动、蹲下、受击、暂停或完成时取消；其他交互仍按住。蹲行按钮在右侧。修机进度为顶部40像素高窄条。

- 放下的木板不遮挡双方视线，也不作为蹲行隐蔽掩体；仍阻挡移动与攻击，可翻越和破坏。

- 攻击改为正前方36度窄角，单刀只命中首个目标。墙、落板和窗台有挡刀音效与火花；窗后蹲下会被窗台保护，站立时可能被刺中。碰撞后本次攻击不再命中其他人。

## 随机长短板地图

每局随机生成12组绕板组合（6长板、6短板），额外24段障碍和12块板，共23块板。长板有120–154单位的长边与75单位短边；短板两侧42–61及45单位，更考验换边。位置、朝向和长边长度每局重新抽取。中央木屋、原有地标和两侧出口固定，保留双层与板窗玩法。新增障碍在渲染、碰撞、视线和AI寻路中使用同一份独立地图数据。

## 地图种子

每次开始或重开自动生成新的32位随机种子，并避免与上一局重复（刷新后也保留上一局种子检查）。种子控制地形、板子、发电机、挂钩和出生分配；对局中AI的随机调用不影响地图复现。桌面左上角与双方暂停菜单显示 F-XXXXXXXX。开发复现可用 new Match(role, seedNumber)，相同种子跨阵营得到相同布局。

- 视野现在按墙体实时裁切整片场景，房屋实墙后区域隐藏；窗洞和门洞仅暴露射线能够穿过的部分。近身视野也不能穿墙，蹲下不能透过木屋实墙；落板仍不遮挡视野。

- 蓄力上限缩短为0.55秒（电脑与手机一致），突刺起手0.035秒，释放后0.065秒开始接触判定，动画收势0.65秒。

- 发电机校准失败时爆炸并锁定3秒，立刻中断所有人的维修与修机声音；冷却期间这台发电机无法维修，其他机不受影响。屠夫破坏完成也有爆炸音效与火花，并保留进度倒退。

- 救下队友交互从2.4秒缩短至1.5秒；挂钩每阶段60秒。搬运自动挣脱：玩家32秒、AI22秒；主动挣扎每0.25秒最多增加1.2%，持续按节奏操作约13秒挣脱，快速连点不会瞬间挣脱。

- 画面保留射线命中的首个墙体或围栏，迷雾从其背面开始。树木、窗户、放倒的木板、发电机不遮挡视野；扇形内未被墙体或围栏遮住的区域正常显示。

- 视野遮挡使用单个平面光照多边形的反向遮罩，遮挡后和视野范围外统一暗化（默认不透明度 0.88）；移除逐射线阴影片段及迷雾条带，避免幕帘式黑线效果。

## 嘲讽语音

七段本地语音：叮叮叮、哎哟我去、哎哟我滴妈、奶龙、小孩糖笑、私人笑声、老牧师。电脑按住 Q 在鼠标位置打开轮盘，移入格子高亮，松开播放；中心 × 或圆盘外松开取消。手机点独立嘲讽按钮打开，点语音播放，点 × 关闭。暂停、失焦和旋转屏幕取消轮盘。

声音在 700 世界单位（约 70m）内随距离线性衰减，楼层差计入距离；播放期间持续更新音量。屠夫听到幸存者语音时显示玩家名、方向、距离与楼层，提示随声源移动并在语音结束后消失。联机由房主验证请求，每位玩家只保留一条播放中的嘲讽，短于 0.25 秒的重复请求被忽略。

## 手机联机与 WebRTC
实时快照接入 GameHub 官方 WebRTC SDK，通过无序、不重传的 state 通道分包传输（每包含 SDK 封装低于 1200 字节）；缺包不应用，等待后续完整帧；每 10 个状态序号通过可靠通道发送一次完整快照。操作和音效事件使用可靠有序的 events 通道。房间、聊天、席位及开局仍通过 WebSocket 管理，ICE 不可用时自动回退 WebSocket。公网穿透使用平台 ice-config 提供的 STUN/TURN；本机 UDP 验证不代表所有公网网络均可直连。协议版本为 3；联机前所有玩家应刷新至相同游戏版本并重新建房。
普通移动由各客户端计算并随操作包上报位置；房主检查席位、序号、状态版本、速度预算、碰撞与楼层后采用，不重复积分行走。收到确认后客户端重放未确认输入并平滑纠偏。战斗、交互、翻越、上下楼及逃生由房主裁定，AI 也在房主运行。远端角色在快照之间插值，缺包时最多外推 0.1 秒，遇到实心地形提前停止；房主渲染远端玩家的位置平滑与战斗判定位置分离。状态快照与可靠事件消息并用，WebSocket 回退时将事件合入状态包以遵守平台发送频率限制。当前没有新增独立 Node 对局服务器。压缩使用 fflate，兼容缺少浏览器压缩流 API 的手机环境。手机画布默认使用 1 倍像素密度，视野多边形按位置、角度缓存；移动时默认逐渲染帧更新，与角色显示位置同步，静止时复用。相关参数见 game-config.json 中的 network、darkwoodVision 和 rendering 字段。

官方 SDK 源码保存在 src/gamehub-rtc.ts，适配与分包在 src/rtc-transport.ts。手机三端延迟、丢包及 CPU 降速模拟脚本为 scripts/mobile-network-stress.mjs；模拟不代表实际手机及公网表现。

## 每轮生成要求
每轮生成的功能，如果参数可变，则需要加入对应json和md中。


石头按完整外形尺寸区分视野遮挡：短边至少 80 世界像素的大石头遮挡；更小的石头（包括随机双石板区）不遮挡，碰撞保持不变。阈值为 `darkwoodVision.rockMinSize`。

白房内部仅概率出现一台电机与地下室入口，无内部隔墙、杂物、内窗或地面钩子；门口板和外墙窗保留。两门分别靠近北侧西角、南侧东角。红光使用独立可见区域遮罩，黑暗遮罩内完全隐藏。
四名求生者全部倒地时不会立即结算，对局继续；失血死亡、挂钩献祭、终局倒计时与逃生规则继续生效。
